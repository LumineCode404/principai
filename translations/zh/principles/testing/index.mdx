title: "测试 · Testing"
description: 软件在工作的证据，并且持续在工作——suite 的形状、行为高于实现、不稳定测试、property、test double，以及 legacy code 的定义。
---

测试不是验证表演——测试是证据，而证据有经济学。每个 test 都在用 runtime、维护成本和注意力换信心。这个类别的原则讲的是如何有意识地付这笔账：把 suite 的形状配好，让 feedback 在变得昂贵之前到达；断言行为而非实现，让 refactor 保持安全；隔离那些随机性会摧毁信任的测试；并且认清一件事——没有测试的代码不是旧代码，是不可更改的代码。

registry 的 testing domain 里还有比这更多的条目——上面这些已深挖、带来源；其余的以 *belum digali*（未深挖）诚实追踪，直到被研究并写成为止。已深挖的类别不等于完成的类别。
