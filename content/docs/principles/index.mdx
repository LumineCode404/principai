Every principle is one markdown file: a summary sized for INDEX loading, a fixed section order, [severity](/docs/concepts/severity), `applies_to`, tags, and aliases. The categories below are marked *sudah digali* — dug, with files on disk. Categories not listed here are tracked in the [taxonomy](/docs/taxonomy) as *belum digali* or *tidak yakin*; the list below is not a promise of coverage.

This is the archive. What loads into an agent is a different concern — handled by [profiles](/docs/profiles) and the [`principai copy`](/docs/cli/reference) command.

## How to load these

Browse by category, or start from a [profile](/docs/profiles) — a curated must-follow and consider set for a kind of work. The [destructive-ops profile](/docs/profiles/destructive-ops) is the canonical example, built from the cleanup-script failure chain.
