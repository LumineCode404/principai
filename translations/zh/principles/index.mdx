每条原则都是一个 markdown 文件：一段为 INDEX 加载而设计的摘要、固定的章节顺序、[severity](/docs/concepts/severity)、`applies_to`、tags 和 aliases。下面的类别都标记为 *sudah digali*（已深挖）——文件已在盘上。未深挖的类别在[分类图](/docs/taxonomy)中追踪。

这是档案本体。什么被加载进 agent 是另一件事——由 [profile](/docs/profiles) 和 [`principai copy`](/docs/cli/reference) 命令处理。

## 如何加载

按类别浏览，或从 [profile](/docs/profiles) 开始——为某类工作策展的 must-follow 与 consider 集合。[destructive-ops profile](/docs/profiles/destructive-ops) 是经典范例，从清理脚本失败链构建而来。
